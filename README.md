# OPENK · Open Knowledge

> 让先进技术，不再卡在门槛上。

**OPENK = Open Knowledge。** 一个把前沿工具拆开、讲清、免费交付的开源计划：用**简单教程**降低上手门槛，用**底层逻辑拆解**让人真正理解原理，让技术传播从“听说很强”变成“我也能用、我也懂为什么”。

## 我们在做什么

先进技术并不缺，缺的是“到我手里能用”的那一步。OPENK 只做三件事：

1. **把工具做成能直接用的东西**：优先零依赖、单文件、双击可运行。
2. **把原理写成看得懂的教程**：工具和教程同源，照着做就能复现。
3. **把结果做成可核对的产物**：给出数据、结构和自检说明，而不是一句“已完成”。

## 原则

- **免费开源**：代码与教程公开，不设付费墙。
- **本地优先**：数据在自己的机器上处理，默认不上传。
- **可验证**：导出物带来源、数量与异常标记，欢迎复核。
- **克制的工具**：不做全能平台，一个工具解决一个具体问题。

## 怎么用

每个工具文件夹内都有独立的 README 与教程。通常两步：获取并运行工具，然后按教程操作。

- 没有编程基础：优先选带 `exe` 的版本。
- 有 Python，或想让大模型代劳：选脚本版，配合文件夹内的提示词使用。
